## 1-Click Terminal Quick Install

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/One-Day-Developers/screen-dangle/main/install.ps1 | iex
```

### macOS (Terminal)
```bash
curl -fsSL https://raw.githubusercontent.com/One-Day-Developers/screen-dangle/main/install.sh | bash
```

## Features
- **Zero-Click Pass-Through**: Clicks and keystrokes pass transparently to applications underneath.
- **Verlet Physics**: Natural rope oscillation and damping with adjustable sway and gravity.
- **Live Web Sync**: Seamless 1-click sync with the online studio at od2.in/screen-dangle.
- **Keyboard Shortcuts**:
  - `Ctrl + D` (Windows) / `Cmd + D` (macOS): Toggle talisman visibility.
  - `Ctrl + S` (Windows) / `Cmd + S` (macOS): Trigger gentle breeze sway / blessing.
  - Right-click tray / menu bar icon: Settings, position, or exit.
